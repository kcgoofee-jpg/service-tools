使用须知

  • 额度每日重置。用完当天额度后，次日自动恢复。
  • 长期不用会被回收。领取后连续 天没有任何请求的 Key 会被自动删除，名额让给其他人；之后可以重新领取。
  • 一人一把，请勿分享 Key。为防止分享，本站会记录你使用 Key 时的来源网段（只保留打码后的前两段，不保存完整 IP，7 天后自动删除）；同一把 Key 短时间内出现在多个网段时，站长可能会来确认。如果泄露，请在 Discord 使用 /resetkey 重置。
  • 生成变慢时，先看页面上方的服务状态，上游限流时稍等片刻再试。
  • 禁止违禁内容。违规的 Key 会被停用。
