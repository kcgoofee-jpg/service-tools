智绘姬（st-chatu8）推荐设置
  1. 「站点」选 其他站点，接口地址填完整地址（接口地址后拼 /ai/generate-image，带路径，不要只填根地址）——只填根地址的话，遇到限流插件会多发一个无效请求。
  2. 「生图间隔时间」从默认 100ms 调到 15000 以上（毫秒）——本站全站每 15 秒放一张，默认值会连续撞限流。
  3. 一条回复尽量只放 1~2 个 image 标签；「自动点击生成」「永久自动点击」保持关闭（默认已关）。
  4. 多人共用的高峰时段建议开启「启用云端队列」（默认队列地址即可）——排队由插件的队列服务承担，生图请求会被排好队再发到站里。
  5. 遇到 429 表示本时段份额用完，等 1~2 分钟再点（插件不会自动重试，也不会自己多发请求）；402 /「需要有效订阅」是额度问题；403 是 Key 被暂停，提示里会写原因。

使用须知

请仔细阅读以下规范，合理使用公益资源，避免被限流或封禁。

  • 客户端怎么填：生图客户端（Aaalice 启动器 / 酒馆 SillyTavern / DSH 插件 / 柏宝绘 / 智绘姬 等）接口地址填 —（末尾不要加 /v1），API Key 填你领到的专属 Key。
  • 出图模型规格：推荐 V4.5 Full 与极速 V5 Full（V5 仅需 4~5 秒完成出图，适合找灵感与快速 Roll 图）。免费尺寸上限 1024×1024 或等总像素（如 832×1216），步数建议 ≤ 28。图生图等付费功能未开通前请在客户端关闭。
  • 一次一张，别狂重试：单并发控制，每把 Key 同时只排队或生成 1 张，出完再发下一张。如遇排队请耐心等待——1 小时内连续被拒 60 次会自动触发 1 小时安全冷却，到点自动恢复。
  • 查额度、自助换 Key：在 Discord 输入 /quota 随时查看今日剩余免费额度与状态；若怀疑 Key 泄露或遇到配置异常，在 Discord 输入 /resetkey 可一键自助更换新 Key。
  • 一人一把，严禁转售与共用：公益资源有限，Key 仅限本人使用（挂梯子换节点、手机电脑多设备正常使用完全不受影响；多人同时共用或转售会被系统记录证据并回收 Key）。退出 Discord 服务器或长期闲置后 Key 会被自动回收（连续 天没生图）。
  • 合规安全，禁止违禁：严禁生成违反法律法规或极端有害的内容，违规账号将被永久封禁并不再恢复。
